# HaBayit - downloadable books

Public distribution repository of the HaBayit app (free, non-commercial). The app lists the books from `manifest.json` and downloads a book only when the user taps Download. Nothing identifying the user is sent.

This repository holds only books that are cleared for distribution, each with its credit line and licence in `manifest.json`. The master copy of all books is kept in a separate private repository.

Status: empty. The first packs will be added after conversion and checking.
